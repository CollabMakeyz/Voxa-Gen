## Default assignments in Voxa GEN

| Event | Sound |
| --- | --- |
| Click (press / release) | ClickDown / ClickUp |
| Selection | keyboard2 |
| Keyboard interaction | keyboard1, keyboard2, keyboard3 (rotating) |
| Confirmation | keyboard3 |
| Page / panel open, panel close, cancel | openWindow, exitWindow, exitWindow |
| Sequence: add / remove element | noteLay / noteErase |
| Undo / redo | undo |
| Drag start / drag (off by default) / drop | stretch1_UI / stretch2_UI / stretchSNAP_UI |
| Export started / completed | metronome1 / metronome2 |
| Error | hitNoteOpponent |
| Preview feedback (off by default) | hitNotePlayer |

Every event can be enabled or disabled, given its own volume, previewed, and replaced by any
other built-in sound or by a user file (Settings → Interface sounds).
